----------------

OBJECTIVE
----------
Create a fully automated real-time “At-Risk Site” engine.

WHEN:
A power-related alarm appears in “Running NSA Tickets”

THEN:
Automatically create a dynamic risk card for that site.

WHEN:
Alarm clears/disappears from “Running NSA Tickets”

THEN:
Automatically remove the risk card immediately.

--------------------------------------------------

FROM POWER BI:
----------------
Use data from “Running NSA Tickets”:

1. SITE ID
2. PROBLEM DESCRIPTION
3. ASSIGNED TIME

FROM COW RISK DATABASE:
------------------------
Using site_id lookup, retrieve:

1. power_configuration
2. battery_backup_minutes
3. eta_minutes
4. district (if available)

--------------------------------------------------
POWER ALARM FILTER
--------------------------------------------------

Only generate cards for alarms containing:

- power
- high temp
- battery
- rectifier
- generator

Case-insensitive matching required.

--------------------------------------------------
BACKEND REQUIREMENTS
--------------------------------------------------

Create backend risk engine.

Use:
- Node.js
- Express
- Existing backend structure

Create:
- activeRiskCards memory store

Example:

const activeRiskCards = new Map();

KEY:
- site_id

VALUE:
- full risk card object

RISK CARD OBJECT
--------------------------------------------------

Structure:

{
  siteId,
  alarmDescription,
  assignedTime,
  powerConfiguration,
  batteryBackupMinutes,
  etaMinutes,

  etaExpiry,
  severity
}

TIME CALCULATIONS
--------------------------------------------------

Use ASSIGNED TIME as source of truth.

DO NOT use page load time.

batteryExpiry =
assigned_time + battery_backup_minutes

etaExpiry =
assigned_time + eta_minutes

SEVERITY ENGINE
--------------------------------------------------

Severity Logic:

IF:
battery remaining < ETA remaining

severity = "critical"

ELSE:
severity = "normal"

REAL-TIME POLLING ENGINE
--------------------------------------------------

Every refresh cycle:

1. Fetch latest Running NSA Tickets
2. Filter power alarms
3. Create/update risk cards
4. Remove cleared alarms

REMOVAL CONDITION:
If site no longer exists in active power alarms,
remove the card immediately.

--------------------------------------------------

--------------------------------------------------

Use websocket updates.

Backend emits:
